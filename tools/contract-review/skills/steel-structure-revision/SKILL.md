# 钢结构专业分包合同修订

客户立场：专业分包人。专业范围：建筑钢结构制作、运输、吊装和连接安装。核对各阶段计量、钢材价格/变更、连接及检测责任；不得推定采购价格、吨位、运输距离或试验指标。

1. 读取整份原正文、原主审及允许来源，按原规则逐条提交处理说明；不能只处理标题中出现的问题。
2. 已明确的问题通过完整段落替换或正文锚点后插入处理；before 必须为固定段落全文，未改正文由程序保留。不能对表格插入段落。
3. 每个修改绑定原规则，处理说明列出对应 editIds。原未发现问题和待核实项已由程序保留在 savedDecisions，不要重复提交；只对剩余原问题提交 changed/pending，不能遗漏。每轮尽量提交多条相关说明，reason 用一句短中文讲清修改。
4. 保持原合同金额、比例、日期、期限、当事人与机构。新增谈判参数无授权时使用【待确认：参数名称】，或保留原文并 pending；不得凭示范文本虚构约定。
5. 互斥的仲裁/诉讼方案及其他商业选择未经客户确认时不得擅自决定。未解决、缺证及主审未完成项必须 pending，写清具体原因。
6. 不引用记忆中的法律，不把来源待核对标记改成已核对，不因为 debug 状态重复制造客户问题；专业依据不足仍须单独保留疑点。
7. 使用 submitRevision 分批提交，每批最多三处修改、六条处理说明。修改要简洁、可直接放进合同；不要输出报告、代码、文件路径或自由文本总结。
8. 独立核对针对修改后的整份正文；任何机器通过均不等于人工批准。修订建议稿保留原件、版本和每处修改的来源。
