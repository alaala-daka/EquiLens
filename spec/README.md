# 衡鉴规格索引

本目录保存已接受的产品与技术契约。契约描述目标行为，不表示功能已经实现。
当前实现 Next.js 工作台、浏览器 DOCX 编辑、服务端文档版本、SQLite / GaussDB 配置、健康接口和镜像构建配置。
SQLite 已有本地行为测试；GaussDB 真机及业务流程、其他华为云服务验收另行记录。

## 文档边界

- `spec/`：已接受、可验证的契约。变更行为时，同步更新所属契约、实现及验证。
- `docs/`：用户操作、部署说明与历史审查。旧设计仅保留历史上下文。
- `DEVELOPMENT.md`：工程边界与开发约定。
- `CONTRIBUTING.md`：贡献流程和检查命令。
- GitHub Issues：未决方案、实施任务和缺陷。未决方案不写成已接受契约。

每项规则只有一个负责文档，其他文档通过链接引用。实现状态与设计目标分开记录，
未接通的云服务、尚未完成的业务验收不得写成已支持。
