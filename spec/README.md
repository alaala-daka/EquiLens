# 衡鉴规格索引

本目录保存已接受的产品与技术契约。契约描述目标行为，不表示功能已经实现。
当前实现 Next.js 应用入口、shadcn/ui 工作台预览、健康接口和镜像构建配置；业务流程及华为云服务接入尚未实现。

| 文档 | 负责内容 |
| --- | --- |
| [架构](00-overview.md) | Next.js 单体、运行边界、GaussDB 与外部服务、任务执行约束 |
| [产品与验收](01-product.md) | 两阶段范围、四模块、主体与金额、来源与版本、权限、任务语义、AC-01—AC-26 |
| [工作台界面](02-workbench-ui.md) | 文档/规范库页签、本地草稿编辑、Agent 会话区域与界面验证 |

先阅读架构，再查阅行为所属的契约。架构替代产品规格中的历史技术选型；业务验收编号保留。

## 文档边界

- `spec/`：已接受、可验证的契约。变更行为时，同步更新所属契约、实现及验证。
- `docs/`：用户操作、部署说明与历史审查。旧设计仅保留历史上下文。
- `DEVELOPMENT.md`：工程边界与开发约定。
- `CONTRIBUTING.md`：贡献流程和检查命令。
- GitHub Issues：未决方案、实施任务和缺陷。未决方案不写成已接受契约。

每项规则只有一个负责文档，其他文档通过链接引用。实现状态与设计目标分开记录，
未接通的云服务、尚未完成的业务验收不得写成已支持。
