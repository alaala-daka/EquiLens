# EquiLens alaaladaka：已有能力完善与共用机制开发 Plan

> 负责人：甲；任务编号沿用总计划，不重新编号。本文只分配开发任务，不表示实现或验收通过。
> 本文件拥有 A 组详细任务及进度；[总计划](2026-10-27-three-person-development-plan.md)拥有共享契约、跨人依赖、全局约束和共同发布门槛，避免两处重复维护任务状态。

**Goal:** 补齐认证、编辑器、任务预算、成果复核导出及平台验证，为乙丙提供稳定共用机制。

## 1. 职责、前置与交接

负责 A1—A5，兼技术集成；不实现款项算法、证据业务、催款内容，也不代替领域人员发布法律规则。

建议分支：`alaaladaka/foundation-completion`。每个工作包独立提交和审查，保留他人改动，不自动提交、推送、创建 Issue 或部署。

| 交接对象 | 甲接收 | 甲交付 |
| --- | --- | --- |
| 乙 | 业务结果结构、领域校验器、主线接口需求及真实案例问题 | 模型/预算/任务、成果修订/复核/导出；审查工程修复 |
| 丙 | 项目授权守卫、资料/来源读取、项目 Word 适配、对象恢复清单 | 认证入口、编辑器访问接口、统一任务及数据库迁移编排 |

先协调 C0，共同固定类型和守卫；优先交付 A1 账号身份、A2 编辑器访问接口及 A3a 任务准入，解除丙和乙的依赖。随后交付 A3b/c 与 A4，A5 从项目首个数据库闭环就介入，不能留到最后。

开工前阅读[规格索引](../../../spec/README.md)及任务拥有规格；现行约束见[总计划 §2](2026-10-27-three-person-development-plan.md#2-全局约束)，文件所有权见[§4](2026-10-27-three-person-development-plan.md#4-目录与集成所有权)，接口草案见[§5](2026-10-27-three-person-development-plan.md#5-共享交接契约与依赖)。这些接口仍是实施草案，行为缺规格时先更新拥有规格再实现。

## 2. 详细开发任务

### A1 认证 HTTP、登录与会话生命周期（P0）

**文件：** 修改 `src/server/auth/{service,http,index}.ts`、`scripts/manage-account.mts`；拟新增 `src/app/api/auth/login/route.ts`、`logout/route.ts`、`session/route.ts`、`src/app/login/page.tsx`、`src/server/auth/http.test.ts`。

**消费/交付：** 消费现有 AuthService 与迁移账本；交付 C0 的当前账号入口、登录页面及 cookie。丙消费身份，不复制密码核验。

- [ ] 先测未知账号/错密码同类错误、重复提交、严格 Origin、可信来源限流、撤销/到期、禁用/重置后旧会话拒绝访问。
- [ ] 从可信部署链提取限流来源，不直接相信任意 X-Forwarded-For；实现 Secure/HttpOnly/SameSite cookie、安全错误及失败后密码不回显。
- [ ] 登录成功重查目标权限；用户无项目只显示无项目，不自动获得成员权限。无公众注册/HTTP 账号维护接口。
- [ ] 将业务初始化显式接入运行生命周期并保留 ready 守卫；导入/构建不迁移。补认证会话及旧限流行的有界清理策略和测试。
- [ ] 处理登录态失效、登出前未保存保护；撤权不能由缓存、另存或下载绕过。将私有账号维护入口纳入可验证的运维交付。
- [ ] 定向运行 `pnpm exec tsx --test src/server/auth/*.test.ts src/server/database/migrations.test.ts`，再实测浏览器登录、退出、到期及停用。

**交付标准：** SQLite 下 HTTP/cookie/浏览器闭环；AC-01 的 HTTPS 和 AC-15 项目权限需联同丙及 A5 验收，不能单独标通过。

### A2 编辑器收尾与访问接口（P0，尽早交付接口）

**文件：** `src/lib/documents/editor-session.ts`、拟新增 `editor-access.ts`，`src/components/{document-editor,word-canvas}.tsx` 及相邻测试。

- [ ] 将当前依赖匿名 client 的保存、复制、预检与错误处理抽为访问接口；保留 open/preflight/save/copy/download/失效通知及基础版本、operationId、字节语义。
- [ ] 先保留匿名适配器通过全部原测试，再把项目适配器实现交给丙 C3。共享错误不依赖 DocumentSessionError 的具体匿名语义。
- [ ] 提供整个工作区未保存对象登记接点；乙丙登记事实、款项、成果、任务条件，保存并离开全部成功才导航，失败留在原位置且不重复创建已保存版本。
- [ ] 补 Windows 原生输入法候选选字、人工 Word 往返、StrictMode 双挂载、直接引擎异常和可执行的下载失败检查；按实际结果记录，无法执行的保持缺项。
- [ ] 回归 F6/Shift+F6、菜单和组合输入、70/30 分栏、窄屏、原生 200% 缩放、默认适配/手动比例、冲突副本、导出字节一致。
- [ ] 运行 `pnpm exec tsx --test src/lib/documents/*.test.ts`；输出 `docs/reviews/2026-10-27-three-person-a-editor.md` 或实施当天的同类记录。

**交付标准：** C3 可接入且匿名功能不回归；不把历史已修复缺陷重新列作未实现，也不因修复子项宣称全部 UI/WD 通过。

### A3 模型、共享任务与费用预算（P0）

**文件：** `src/server/ai/`、`src/server/contract-review/tasks/`、`src/instrumentation.ts`；拟新增 `src/server/tasks/{repository,runner,budget,service}.ts` 及对应测试。

- [ ] A3a：先实现持久化提交和原子准入，测试同键同输入返回原任务、同键变输入冲突、第 11 排队/第 3 同用户未终结拒绝及竞争不越界。
- [ ] A3b：实现调用/时间/任务费用/项目费用分别持久预留；测试预留后崩溃、用量未知、重试恢复不清零、未登记/不足时没有外部请求。
- [ ] A3c：合并为一个全局串行 runner；任务领取、每阶段读取、外发与写回重验权限/租约/令牌，测试旧尝试迟到、双领取、撤权及取消的既有匿名语义。
- [ ] 保留匿名审查 contextId、固定期限及删除就绪屏障；新增项目任务不读取匿名 canSave。项目界面不自行新增无服务端契约的取消操作。
- [ ] 固定批量父任务、解析、事实准备、分析和导出的共享调度方式；人类确认在任务完成后另存版本，不占运行任务等待。
- [ ] 复用已有兼容网关并补 MaaS server-only 适配；登记真实目标、模型、上下文、请求/输出限制、价格来源、额度和安全日志。未验证不宣称供应商支持。
- [ ] 保存真实阶段、部分结果和用量；断线仅为状态获取失败。永久 4xx 不重试，非法/截断/拒绝不得回退演示答案。
- [ ] 运行 `pnpm exec tsx --test src/server/tasks/*.test.ts src/server/ai/*.test.ts src/server/contract-review/tasks/*.test.ts`，按变更运行 Agent 离线回归；真实调用另记外发范围、授权及费用。
- [ ] `tools/contract-review/src/gateway.ts` 等乙维护的调用接点，由甲提供统一预算/权限/模型适配接口后交乙接入；不保留能绕过外发预留的第二条正式调用路径。

**交付标准：** 乙丙均通过同一入口提交；并发、预算、恢复及匿名回归有独立测试，正式模型预算实测有单独记录。

- [ ] 实现保存后重验/重置待复核、只读下载既有文件、无效引用/缺必填项阻断有效结论导出；草稿及问题导出遵循产品边界。

- [ ] 运行 `pnpm exec tsx --test src/server/results/*.test.ts src/server/exports/*.test.ts`；实际打开 Word 核对已保存正文、表格和状态标记。

**交付标准：** 乙的审查报告/催款函和丙的两模板/核验报告均能复用；导出模块没有模型调用路径。
