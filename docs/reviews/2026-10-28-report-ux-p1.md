# 报告阅读、导出与款项结论（P1）

日期：2026-10-28。分支：`feat/report-ux-p1`。

## 已改

### 报告阅读
- 任务结果区增加“展开报告”，用宽对话框承载完整报告；原右栏仍保留快速阅读。
- 报告导出增加 Word；Markdown 保留为次要入口。
- 处理记录显示“第 N 次 · 业务 · 时间 · 状态”，不再只显示相同文档标题。

### 款项核对
- 提交前显示建议材料清单：合同/付款条款、计量/结算资料、付款凭证、收付款汇总/对账确认；并说明材料不足只能做有条件测算。
- 结果顶部增加“本次核对结论”：
  - 有计算：显示有条件未付金额，并明确不能作为确定欠款；
  - 无计算：明确“不能形成确定金额结论”，引导补材料后重提；
  - 显示金额条目已核对/待复核数量。
