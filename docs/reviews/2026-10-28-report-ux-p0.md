# 报告与引用体验改进（P0）

日期：2026-10-28。分支：`feat/report-ux-p0`。范围：提交前信息、报告呈现、引用核对、等待状态；不改业务数据模型。

## 已改

### 引用核对
- 引用弹窗不再展示文档版本/解析快照 UUID，只显示段号、表格位置和原文。
- 新增“在正文中定位”：按引文匹配正文，选中并高亮所在段落约 4 秒，滚动到视口中央；找不到时提示“当前正文已变化”。
- 浏览器实测：弹窗无 UUID，点击后选中并高亮第 8 段原文，弹窗关闭。

### 报告
- 每条问题显示风险 Badge（重大/一般/提示/待核实），类别按最高风险排序。
- 顶部增加重大/一般/提示数量；问题类别只保留“审查发现”一套，删除重复的“需要进一步确认”区块。
- 阶段性结果只在顶部提示一次，删除每条问题重复的“复查未完成”和底部重复的复查说明。
- 删除报告底部的内部报告/文档/快照 UUID；技术信息不再面向普通用户。

### 提交前
- 地域改为可输入省级候选，失焦和提交时统一去掉“市/省/自治区/特别行政区”等后缀；增加“地域用于确定适用规则和审查范围”的说明。
- “审查选项”和“数据与外发确认”拆成两个独立区块；生成修订稿不再和第三方外发授权混在同一组复选框。
- 确认文案改为“发送给第三方模型服务”，服务地址/模型/留存说明放进折叠详情；移除 token、停止阈值和“2–3 倍 token”等内部术语。

### 等待与噪音
- 阶段文案改为“正在读取合同 / 正在识别合同场景 / 正在核对合同条款 / 正在复核结论”等，并显示已用时和已读段落进度。
- 删除编辑器和工作台顶部的“源代码”入口；处理记录不再展示任务 UUID（仅保留用户可理解的时间/状态）。
- 修订建议入口的“调用和 token”改为“处理时间和调用次数”。
