## 3. 关键本地验收证据

- **完整项目恢复（C7+A5）**：quiesced 备份（数据库 VACUUM INTO + 对象清单/摘要 + 删除日志 + 应用/模板版本 + 配置名 + 密钥恢复说明）→ 新根恢复 → 离线重放 → 纯 HTTP 22/22 检查通过（登录、原件字节+sha256、来源逐字、要求集/比较/复核、草稿、导出下载 sha256、任务/预算历史、已删项目拒绝且列表不可见、删除状态 no-store）；删除前备份重放不复活已删项目（revoked=1/reclaimed=1），删除后备份重放 no-op（全计数器 0），保留项目完整。
- **卷式重启**：同数据目录重启后 `smoke-database --verify` 通过（含 integrity_check/foreign_key_check 跨重启）。
- **迁移账本**：13 个迁移（0001—0013）空库应用、重复启动、摘要冻结、漂移/截断拒绝、失败回滚；0001—0012 摘要未变。
- **容量**：仓储层确定性边界（每用户未终结 2、全局排队 10、幂等/409/租约恢复）+ HTTP 5 合成用户并发 35 请求 = 30×200 + 5×201、0 失败、p50 144.55 ms / p95 256.37 ms / max 272.94 ms（本机合成，不承诺 SLA）。
- **丢失窗口**：演练前停止写入取得一致备份，实测已提交写入损失 0；生产 RPO 取决于备份频率，未宣称。
