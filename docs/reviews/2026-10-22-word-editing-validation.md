## 一致性复查

生产页面首次连续“跳转末尾 → 输入 → 改标题 → 导出”时观察到正文标题意外变化，
后续单步与连续复测未重现；根因尚未确认，异常样本不作为通过证据。
已增加序列化期间的输入锁定、独立编辑快照、导出前后正文比对、DOCX 正文文字比对和异常恢复。
文字比对保留段落/表格的交错顺序、空白、数字字符串及 XML 实体，不以丢弃文字换取保存成功。
最终生产构建连续两次执行“跳转末尾 → 输入 → 立即导出”，成功保存和重开；
下载字节通过标题、表格顺序、`001.00`、`&` 及末尾新增文字核对，未观察到正文变化。
首次异常文件保留在忽略的 `.superpowers/previews/word-fixtures/failed-first-export.docx`。
这些保护不能替代 Word 人工核对，也不能据此宣布所有编辑器一致性场景均已通过。
