## 6. 实现中修正的问题（均在本轮提交内）

1. **催款函主体映射方向**：款项记录中付款方对应收函方、收款方对应发函方；初版比较方向写反，会拒绝合法催款函（`letters.test.ts` 覆盖）。
2. **草稿字段被 schema 拒绝**：发函与送达计划允许为空并渲染 `【待补充】`，初版按必填校验导致草稿不可保存；改为允许空值、由组装函数记录 `missing` 并产出 `draft`。
3. **正文占位符污染原值**：初版把 `【待补充】` 写回字段值，导致校验器重建结果与保存值不一致（成果被判 invalid）；改为字段保留原值、只有正文使用占位符。
4. **证据项更正未传 itemId**：服务层未把 `itemId` 传给仓储，更正会被当成新建并触发基础版本冲突。
5. **canonical JSON 拒绝 undefined**：报告 value 中显式 `undefined` 字段导致保存失败；组装时统一剔除。
6. **证据报告旧表分离**：0015 只建证据项表；旧 `equilens_evidence_reports` 保留为运行时遗留表（删除清单仍覆盖），项目主线报告走 `equilens_results`。
